# OutlineCircle

Geospatial data pipeline orchestrator for near-real-time data aggregation and visualization within a web-based Explorer dashboard.

OutlineCircle is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Geospatial data pipeline orchestrator for
- near-real-time data aggregation and visualization
- within a web-based Explorer dashboard

## Key Features

- Geospatial data pipeline orchestrator for
- near-real-time data aggregation and visualization
- within a web-based Explorer dashboard

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineCircle.git`
2. `cd OutlineCircle`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineCircle is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
